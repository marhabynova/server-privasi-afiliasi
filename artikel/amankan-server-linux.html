5 Langkah Amanin Server Linux dari Serangan Brute-Force

Update 2026

Server baru langsung kena scan bot dalam hitungan menit setelah online. Ini 5 langkah dasar yang wajib, urutan dari paling penting:

  1. Jangan buka SSH ke internet umum. Kalau punya mesh VPN (Tailscale/WireGuard), batasi SSH cuma reachable dari situ: 
    firewall-cmd --zone=public --remove-service=ssh --permanent
firewall-cmd --zone=trusted --change-interface=tailscale0 --permanent
firewall-cmd --reload
  2. Pasang fail2ban — auto-ban IP yang gagal login berkali-kali: 
    [sshd]
enabled = true
maxretry = 4
bantime = 3600
  3. Matiin login password, wajib SSH key. Password bisa di-bruteforce, key praktis nggak bisa.
  4. Kernel hardening dasar lewat sysctl: kernel.kptr_restrict=1, net.ipv4.conf.all.rp_filter=1, matiin ICMP redirect.
  5. Auto-update security patch. Kebanyakan breach itu lewat CVE lama yang harusnya udah dipatch berbulan-bulan sebelumnya.
